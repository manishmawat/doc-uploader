# Azure Deployment Checklist ✅

Use this checklist to track your deployment setup and go-live process.

## Pre-Deployment Setup (Choose ONE path)

### Path A: Static Web Apps Direct ⭐ RECOMMENDED

- [ ] **GitHub Repository Ready**
  - [ ] Code pushed to GitHub
  - [ ] Main branch is default
  - [ ] Repository is accessible

- [ ] **Azure Setup**
  - [ ] Azure account active
  - [ ] Logged into Azure Portal
  - [ ] Know your region (e.g., East US)

- [ ] **Create Static Web App in Azure Portal**
  - [ ] Resource Group: Choose existing or create new
  - [ ] Name: `uploaderapp` (or your choice)
  - [ ] Hosting Plan: Free or Standard
  - [ ] Region: Configured
  - [ ] Deployment token generated ✓

- [ ] **GitHub Secret Configuration**
  - [ ] Repository Settings → Secrets opened
  - [ ] New secret created: `AZURE_STATIC_WEB_APPS_API_TOKEN`
  - [ ] Deployment token pasted (without "Bearer " prefix)
  - [ ] Secret verified in settings

- [ ] **Ready to Deploy** ✓
  - [ ] All files in project
  - [ ] No uncommitted changes
  - [ ] Ready to push to main

### Path B: Full Infrastructure with azd

- [ ] **Prerequisites**
  - [ ] Azure CLI installed: `az --version`
  - [ ] GitHub CLI installed: `gh --version`
  - [ ] Logged into Azure: `az login`
  - [ ] Logged into GitHub: `gh auth status`

- [ ] **Run Setup Script**
  - [ ] Windows: `.\scripts\setup-github-deployment.bat`
  - [ ] macOS/Linux: `./scripts/setup-github-deployment.sh`
  - [ ] Script completed without errors
  - [ ] GitHub Secrets created automatically

- [ ] **Environment Configuration**
  - [ ] `.azure/.env` created from `.env.example`
  - [ ] `AZURE_ENV_NAME` set
  - [ ] `AZURE_LOCATION` set
  - [ ] `AZURE_SUBSCRIPTION_ID` set

- [ ] **Ready to Deploy** ✓
  - [ ] All configuration verified
  - [ ] No uncommitted changes
  - [ ] Ready to push to main

## Initial Deployment

### Before Pushing

- [ ] **Code Review**
  - [ ] No syntax errors in source
  - [ ] UploaderDoc.csproj is valid
  - [ ] Program.cs compiles locally
  - [ ] All dependencies resolved

- [ ] **Local Testing** (Optional but recommended)
  - [ ] `dotnet restore` succeeds
  - [ ] `dotnet build` succeeds
  - [ ] `dotnet run` works locally
  - [ ] App loads at http://localhost:5168

- [ ] **Files Committed**
  - [ ] All new files staged: `git add .`
  - [ ] Commit message clear: `git commit -m "Add deployment configuration"`
  - [ ] Ready to push: `git status` is clean

### First Deployment

- [ ] **Push to Repository**
  ```bash
  git push origin main
  ```
  - [ ] Push completed without errors
  - [ ] GitHub shows new commits

- [ ] **Monitor GitHub Actions**
  - [ ] Repository → Actions tab opened
  - [ ] Latest workflow visible
  - [ ] Build started automatically
  - [ ] Workflow name: "Deploy to Azure Static Web Apps" or "Deploy Infrastructure and App with azd"

- [ ] **Wait for Build**
  - [ ] Build step completed (2-3 minutes)
  - [ ] No build errors in logs
  - [ ] Publish successful
  - [ ] Ready for deployment

- [ ] **Wait for Deployment**
  - [ ] Deployment step running (2-5 minutes)
  - [ ] No deployment errors
  - [ ] Workflow shows "Success" ✓
  - [ ] Deployment URL visible in output

### Verify Deployment

- [ ] **Get Deployment URL**
  - [ ] Click workflow run in Actions
  - [ ] Find deployment URL in output
  - [ ] Copy the URL (e.g., `https://<auto-generated>.azurestaticapps.net`)

- [ ] **Test Application**
  - [ ] Open deployment URL in browser
  - [ ] Page loads successfully
  - [ ] No console errors (F12 → Console)
  - [ ] Layout renders correctly (FluentUI visible)

- [ ] **Test Features** (if configured)
  - [ ] Navigation menu works
  - [ ] Authentication works (if configured)
  - [ ] File upload section visible
  - [ ] PDF features accessible

- [ ] **Browser Checks**
  - [ ] HTTPS enabled (🔒 visible)
  - [ ] No mixed content warnings
  - [ ] No 404 errors for assets
  - [ ] Service worker registered (DevTools → Application)

## Troubleshooting Reference

If any step fails, check:

| Issue | Check | Solution |
|-------|-------|----------|
| Build fails | GitHub Actions logs | Verify .NET 9.0 compatibility |
| Deploy fails | GitHub Secrets | Confirm token/credentials |
| Page won't load | Static Web App URL | Wait 2+ min for DNS |
| Assets missing | Browser DevTools | Check wwwroot/ published |
| Auth fails | Azure AD B2C config | Verify appsettings.json |
| Storage errors | Storage Account created | Check if Path B completed |

**Full support:** See DEPLOYMENT_GUIDE.md → Troubleshooting
